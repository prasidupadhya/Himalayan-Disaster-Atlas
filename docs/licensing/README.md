# Licensing and attribution

The synthetic fixture in `tests/fixtures/sample-source.csv`, its generated `foundation-sample` releases and corresponding public copies are dedicated under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). No external geographic datasets or basemaps are bundled.

A license for the project's original application code has **not** been selected. Do not assume this fixture dedication licenses the whole repository or choose a project-wide license incidentally during Foundation.

Dependencies retain their own licenses. The lockfile pins installed packages; distribution must preserve applicable notices. Core runtime dependencies: Next.js, React and React DOM (MIT), MapLibre GL JS (BSD-3-Clause), Ajv and ajv-formats (MIT). Offline validation: jsonschema (MIT) and Shapely (BSD-3-Clause; wheels include GEOS, which has its own LGPL terms). This is a core dependency summary, not the final transitive distribution audit. The dedicated licensing feature must review all distributed dependencies and assets.

Every future dataset needs its precise release license, source attribution, redistribution constraints, and source/license links recorded. Accessibility of a download or API does not grant redistribution rights. If terms are unclear, do not publish the artifact as an authoritative public layer.
