# Foundation scientific assumptions

There are no hazard, exposure, population, drainage, terrain or simulation calculations in Foundation. The only spatial behavior is displaying synthetic coordinates and verifying their geometry and coverage. This does not establish any causal or hydrological relationship.

The sample's missing values are unknown, not zero. A source completeness check does not independently establish accuracy. Estimates and model outputs require separate evidence statuses, explicit assumptions and uncertainty. Hypothetical simulation outputs must never be presented as forecasts or official warnings.

Later algorithm owners must add method-specific documentation, validation benchmarks, sensitivity/uncertainty treatment, source/version references and limitations before publishing scientific results.
