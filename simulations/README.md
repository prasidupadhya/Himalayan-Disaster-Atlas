# Simulation extension boundary

Reserved for versioned model adapters and independent scenario contracts. No simulation is implemented. A future engine must separate observations, hypothetical scenario inputs and MODELLED outputs; record model/version, parameter units/ranges, immutable input versions/hashes, CRS, assumptions, validation, uncertainty and limitations. Level 1 terrain/network approximations must not claim hydraulic inundation, arrival times, damage or forecasts. See the feature specification for full implementation scope.
