Getting Started
Read the
Getting Involved
page to begin contributing to OpenStreetMap.
Simply, follow these steps:
Sign up
and
Login
Zoom in to your area of interest, or pick an at random (large cities tent to have more to do, but also roads and rivers in rural areas).
Click the edit tab at the top to switch to the online map editor (called '
iD
').
Start tracing over the imagery by drawing lines and polygons.
For your elements to render on the map, the points and lines must be tagged appropriately. Select classifications on the left had side. See
Map Features
for tagging details. Incorrectly tagged objects will not show up on the map.
Done. Happy Mapping :D
Mappers are encouraged to use the
JOSM
offline editor once you are familiar with the basics and want to map large areas in much more detail.
Please see
Nepal remote mapping guide
for help with identifying features in Nepal's aerial imagery.

Naming Conventions
The attribute name will always be in native name in Nepali unicode. Example: Use "नेपाल" for the name keyword. Always use the official name when possible. If another name is more popular name:alt can be used. To write the names in other script, use name:en, name:ne, etc.

Downloads for Nepal
Generating own extract for Nepal
Geofabrik provides extracts for Nepal in various formats, see
http://download.geofabrik.de/asia/nepal.html
The idea is to download asia.osm extract from
Geofabrik
, polygon from
Cloudmade
, cut with
Osmosis
. Here are the steps:
Go to
http://download.geofabrik.de/openstreetmap/
and download asia.osm.pbf (pbf files are smaller in size)
Go to
http://downloads.cloudmade.com/asia/southern_asia/nepal#downloads_breadcrumbs
and download nepal.poly
Download and install
Osmosis
Run the command to create an extract nepal.osm
```
./osmosis --read-binary file="asia.osm.pbf" --bounding-polygon file="nepal.poly" --write-xml file="nepal.osm"
```
In case of normal .osm file
```
./osmosis --read-xml file="asia.osm" --bounding-polygon file="nepal.poly" --write-xml file="nepal.osm"
```
