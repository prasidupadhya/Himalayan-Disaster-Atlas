This is used to include names in Nepali, written with the
Devanagari script
. This should reflect local pronunciation accurately.
Note that the name normally used in other languages, including Hindi, Urdu and English, may differ in pronunciation.
Note that this tag is useful when an object has names specified in more than one language:
If
`name=*`
is in Nepali then it specifies which language is used in the main name tag
If
`name=*`
is in a different language then it specifies the name in Nepali
